# Assets Directory

Place your personal assets here:

### 📸 Profile Photo:
- Save your photo in this folder as **`profile.jpg`** or **`profile.png`**.
- The website is already configured to automatically detect and display it!
- If no photo is found, it will safely show the gradient vector avatar (`avatar.svg`).

### 📄 Resume / CV:
- Save your resume in this folder as **`resume.pdf`**.

### 💻 Project Screenshots:
- You can add preview screenshots for your projects here (e.g., `project1.png`, `project2.png`).
